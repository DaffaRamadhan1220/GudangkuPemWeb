# GudangKu — Revisi berdasarkan Rubrik Penilaian

## Teknologi
- React + Vite
- Bootstrap 5.3.8 untuk komponen, grid, form, tabel, dan responsive utilities
- Tailwind CSS v4 untuk utility styling tambahan
- Bootstrap Icons

## Menjalankan aplikasi
1. Pastikan Node.js versi yang kompatibel dengan Vite 8 sudah terpasang.
2. Buka terminal pada folder proyek.
3. Jalankan `npm.cmd install`.
4. Jalankan `npm.cmd run dev`.
5. Buka alamat localhost yang muncul di terminal.

## Build pemeriksaan
Jalankan `npm.cmd run build` untuk memeriksa apakah proyek berhasil dikompilasi.

## Catatan rubrik
- Uji setiap halaman pada desktop (misalnya 1366×768) dan mobile (misalnya 390×844).
- Pastikan seluruh navigasi, tombol, formulir, tabel, dan aksi CRUD diuji.
- Bootstrap dan Tailwind sudah dikonfigurasi; Tailwind utilities digunakan pada kartu statistik dashboard.
- CSS fokus keyboard ditambahkan untuk tautan, tombol, dan kontrol form.
- Walkthrough individu tetap harus dilakukan oleh mahasiswa: pahami alur login, routing, state, localStorage, CRUD, transaksi, dan komponen dashboard. Kode tidak dapat menjamin nilai walkthrough tanpa penjelasan langsung.
